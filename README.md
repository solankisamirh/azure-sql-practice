# Azure SQL Practice

A small practice project where I set up a free-tier Azure SQL Database
and worked with it from VS Code using the MSSQL extension.

## What's inside
- `01_create_tables.sql`: creates a `Telescopes` table with an identity primary key and a default value
- `02_insert_data.sql`: adds four sample telescopes
- `03_queries.sql`: reads the data back and creates a stored procedure, `GetAvailableTelescopes`, that lists available telescopes by aperture

## Tools
Azure SQL Database (free tier), T-SQL, VS Code with the MSSQL extension
