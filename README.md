# Azure SQL Practice

A small practice project where I set up a free-tier Azure SQL Database
and worked with it from VS Code using the MSSQL extension.

## What's inside
- `01_create_tables.sql`: creates the [table names] tables
- `02_insert_data.sql`: adds sample data
- `03_queries.sql`: queries including [joins / filters / grouping]

## Tools
Azure SQL Database (free tier), T-SQL, VS Code with the MSSQL extension
